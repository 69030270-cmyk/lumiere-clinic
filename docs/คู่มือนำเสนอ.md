# Lumiére Clinic — คู่มือนำเสนอ

## เริ่มต้น

เปิด MySQL Server เปิด `main.py` ใน Thonny แล้วกด F5 เปิดโปรแกรมให้เต็มหน้าจอเพื่อแสดงภาพได้ชัดเจน รอข้อความ “พร้อมให้บริการ” ชื่อผู้ใช้ไม่จำกัดตัวพิมพ์ใหญ่/เล็ก แต่รหัสผ่านต้องพิมพ์ให้ตรง

| หน้าที่ | บัญชี | รหัสผ่าน |
|---|---|---|
| ผู้รับบริการ | customer | Demo12345 |
| ผู้ดูแลระบบ | admin | Demo12345 |
| แพทย์ | doctor1, doctor2, doctor3 | Demo12345 |

หน้า Login มีเฉพาะชื่อผู้ใช้และรหัสผ่าน ระบบตรวจบทบาทจาก MySQL หลังยืนยันรหัสผ่าน ไม่แสดงช่องเลือกบทบาท

ปุ่ม “◉ แสดง” ข้างช่องรหัสผ่านใช้ตรวจตัวอักษร กดซ้ำเพื่อซ่อน มีให้ทั้งหน้า Login สมัครสมาชิก กู้รหัสผ่าน และช่องข้อมูลลับอื่น

## ลำดับสาธิตประมาณ 8–10 นาที

1. แนะนำแบรนด์และหน้า Login แสดงการกดซ่อน/แสดงรหัสผ่าน
2. เข้าบัญชี customer แนะนำหน้าโปรไฟล์และแต้ม
3. เปิดแท็บ “บริการและหัตถการ” ชมภาพบริการทั้ง 5 รายการ เปิดรายละเอียดเพื่อแสดงราคา เวลา ข้อดีและการพักฟื้น
4. กด “จองบริการนี้” ระบบพาไปหน้าจองและเลือกหัตถการให้ ภาพตัวอย่างและราคาเปลี่ยนตามหัตถการ
5. เปิดปฏิทิน แสดงว่าวันพุธและวันที่ผ่านไปกดไม่ได้ เลือกวันเปิดทำการและเวลาอนาคตที่ยังเปิดรับจอง แล้วกดยืนยัน
6. ออกจากระบบ เข้า admin ค้นหาคิวใหม่ อนุมัติ ยืนยันนัด และส่งข้อความประสานงานถึงแพทย์ที่เลือก
7. เข้า doctor1 หากจองกับแพทย์ท่านแรก หรือ doctor2/doctor3 ให้ตรงกับแพทย์ของคิว แสดงตารางเฉพาะแพทย์และเปิดเคสดูข้อความประสานงาน
8. คิวในวันปัจจุบันที่อนุมัติแล้วสามารถกดเริ่มหัตถการ บันทึกการรักษาและคำแนะนำ กดเสร็จสิ้น แล้วแสดงแต้มและรายได้จำลองที่เพิ่มขึ้น
9. สาธิตลืมรหัสผ่านเป็นลำดับสุดท้าย หากเปลี่ยนรหัสบัญชีทดลองแล้ว รหัสใหม่จะมีผลจริง คำตอบกันลืมเริ่มต้นคือ `beauty`

หากต้องการนำเสนอการเริ่มและเสร็จสิ้นบริการในครั้งเดียว ให้เลือกจองเวลาในวันนี้ที่ยังไม่ผ่านไปและไม่ใช่วันพุธ หากพ้นเวลาทำการหรือเป็นวันหยุด ระบบจะบังคับให้จองวันถัดไปตามกติกา จึงนำเสนอขั้นตอนเริ่มบริการได้ในวันนัดจริงเท่านั้น

## ข้อมูลและภาพ

ภาพทั้งหมดเป็นภาพจำลองที่สร้างด้วย image_gen ไม่ใช่คนไข้จริงหรือการรับรองผลรักษา อยู่ใน `assets/` และโหลดจากเครื่องได้โดยไม่ใช้อินเทอร์เน็ต มีทั้งโบท็อก ฟิลเลอร์ Ultraformer การปรึกษาเสริมจมูก และตัวอย่างอุปกรณ์เพื่อการปรึกษาเสริมหน้าอก พรอมป์ต์อยู่ใน `assets/treatment_prompts.txt` และ `assets/breast_prompt.txt`

ฐานข้อมูลเดิมยังอยู่ ไม่มีการรีเซ็ตรหัสผ่านหรือลบประวัติผู้ใช้จริง การทดสอบระบบใช้ฐานข้อมูลทดสอบแยกและลบเฉพาะฐานข้อมูลทดสอบหลังจบ

โปรเจกต์นี้เป็น Desktop Application ด้วย Tkinter ไม่ต้องเปิดเว็บเบราว์เซอร์ รายได้ การประสานงานในแอป และข้อมูลหัตถการใช้สำหรับสาธิต ไม่มีการชำระเงินจริงหรือส่ง SMS/LINE
